# 定着の可視化を「左ドットの星型」に統一し、Today 見出しを「定着 N 個」にする（Issue #118 と #211/#213 を反転）

## 文脈

ADR-0047 の定着ライフサイクル実装で、定着の見せ方が短期間に何度も変わった:

- 定着マーカー: Issue #118 で「左の SVG マーカーは常に円、定着の祝福はアクション名右の小さな ★」と決めた（旧 v0.3 の「円→星」形変化は撤回済み）。
- Today の定着達成: 当初 auto-✓ → 07-06 タップ従来どおり → 07-07（#211）auto-✓・タップ不要に再反転。
- 累計: #213 で「定着 auto 日を派生で数える」effective 累計に。

実機で見返した結果、ユーザーが次の方針を確定した（2026-07-07）: **定着は「星」という一貫した記号で、Today のノードドット・7 日ミニマトリクス・60D マトリクスすべてに出す。定着に変わっていく様（達成の四角 → 定着の星）を見せたい。Today の見出しは累計ではなく「定着 N 個」を主役にする。**

## 検討した選択肢

- **案 A (採用)**: 定着 = **左ドットを星型**に変える（#118 の「常に円」を反転）。auto-✓（#211）と effective 累計（#213）は撤回し、定着はタップ達成とは別軸のマイルストーン記号（星）にする。Today 見出しは「定着 N 個」。
- **案 B**: #118 を維持（左は円）し、定着は別要素（バッジ等）で示す。→ ユーザーが「ドット自体を星に」を明示選択したため不採用。
- **案 C**: auto-✓（#211）を残す。→ 「自動で ON にはしないでほしい」と明示。星は達成状態ではなくマイルストーンなので別軸にする。

## 決定

1. **定着ノードの左マーカーは星型**（`Polygon` の 5 芒星、常に塗り `COLOR_STAR`）。未定着は従来どおり円（達成でバウンス）。**Issue #118 の「左マーカーは常に円 / 円→星の形変化は撤回」を反転する。** 星は今日の達成状態で塗り分けない（常に塗り = ADR-0036 (−) 禁則・#118 追補の「☆ を使わない」と整合）。
2. **アクション名右の小さな ★（#118 追補）は撤去**。星は左ドットに一本化（二重表示回避）。
3. **auto-✓・タップ不要（#211）を撤回**。定着ノードも**タップは従来どおり有効**（実タップで達成記録）。スパインの伸び・マーカーの塗り（円ノード）は実タップベースに戻す。星は達成とは独立したマイルストーン記号。
4. **effective 累計（#213）を Today 見出しから撤回**。Today 見出し右は「**定着 N 個**」（アプリ全体の定着ノード数・latch・単調増加 (+)）に置換する。累計（実タップ通算）は立ち上げチェックリストのマイルストーン判定にのみ内部利用（見出しには出さない）。
5. **7 日ミニマトリクス / 60D マトリクスの定着日は星で表示**（`settledDatesForNode` 派生）。60D は #212 の「緑塗り」から「星」へ変更（Today と統一）。定着日以外は従来どおり二値の塗り四角（達成/未達/休）。レコードは書かない（K-002）。
6. **ログ（定着ポートフォリオ）は 0 件のステージも見出し（プルダウン）を常に表示**（「もう少しで定着」等が 0 でも構造を安定させる）。

## 理由

- **一貫した記号で「変わっていく様」を見せる**: 達成 = 四角、定着 = 星。同じ星が Today ドット・7D・60D・見出し（定着 N 個）に通底し、「四角が星に変わる」進捗が一目で伝わる。ユーザーの中心的な要望。
- **auto-✓ の撤回**: 「自動で ON にする」は達成状態を書き換えたように見え、達成（実タップ）とマイルストーン（定着）の 2 軸が混ざる。星を別軸の記号にすることで、タップ運用を残しつつ定着を示せる。
- **#118 反転の正当化**: #118 は「左マーカーを派手にすると線（連鎖）の主役性が薄れる」ことを理由に円へ寄せた。今回はユーザーが実機で見て「定着はドット自体を星にしたい」と判断。反 streak / Celebrate 主の核（線の伸び + 星）は保たれ、星は塗り分けをしない（(−) 禁則不抵触）。判定軸（ADR-0036 §一般原則）では定着 = latch = (+) なので星表示は採用可。
- **見出しの主役を定着個数に**: 累計（実タップ総数）より「定着 N 個」の方が本アプリの価値（習慣が身につく）を直接表す。両方 (+) 単調増加で ADR-0036 と整合。

> **追補 (2026-07-07)**: 定着ノードもタップ可能なため「今日 ON/OFF」が星から読めない問題が出た。**今日達成 (実タップ) のときだけ星に白系 (`--grow`) のアウトラインを足す** (additive)。星の塗り (金) は達成状態で変えない。未達は無印 = 星を薄めない (☆ で薄める #113 とは逆・(−) 禁則不抵触)。円マーカーの「塗り=達成」と同じチェックフィードバックの位置づけ。DESIGN-SYSTEM §4.2 同期。

## 想定される影響

- **Issue #118 / DESIGN-SYSTEM §4.2 / SPEC §2 §3 / CLAUDE.md §4** の「左マーカーは常に円」を更新（本 ADR で反転）。ハードガードレール（CLAUDE §4）の該当条文を「定着は星型ドット（塗り分けなし）」に差し替える。
- **#211（auto-✓）/ #213（effective 累計）を撤回**。`ChainDetail` の effective 達成ロジック・累計表示を除去、`useTodayData` は settledCount を出す。`countEffectiveAchievedForNode/Total`（domain）は本 ADR で未使用化（テストは残置・将来削除候補）。
- 60D マトリクスの定着表示は #212（緑塗り）→ 星に変更。
- ADR-0047 §決定4/§決定5 の 07-07 追補（auto-✓ / 緑塗り）を本 ADR が上書きする（逆参照）。
