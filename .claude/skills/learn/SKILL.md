## 手順

### 1. 知見の特定
- 引数がある場合: その内容をもとに知見を構造化
- 引数がない場合: 直近の会話コンテキストから「何にハマったか」「何を発見したか」を抽出

### 2. 分類判断
知見の汎用性を判断する:
- **KNOWLEDGE.md に追記**: このプロジェクト固有の制約・ハマり事例・判断履歴
- **CLAUDE.md or .claude/rules/ に追記**: 今後のAIの行動ルールとして定着させるべきもの
- **両方**: ハマり事例の記録 + 再発防止ルール

### 3. 差分を提案
KNOWLEDGE.md の既存内容を読み、重複がないか確認したうえで、以下のフォーマットで追記内容を提案する:

```markdown
## [今日の日付] タイトル

**状況**: 何をしようとしていたか
**問題**: 何が起きたか
**原因**: なぜ起きたか
**解決**: どう直したか
**教訓**: 次回から気をつけること
```

### 4. ユーザーの承認を待つ
- 提案した差分を表示し、ユーザーの承認を得てから書き込む
- 勝手に KNOWLEDGE.md を編集しない
