# /idea — アイデアキャプチャスキル

開発中に「こういう機能あったらいいな」が浮かんだ時に、PLAN.mdに記録する。
作業を中断しない軽量フロー。

## 手順

### 1. アイデア内容の取得

- **引数あり**: その内容をアイデア概要にする
- **引数なし**: 直近の会話コンテキストから「やりたいこと」を抽出して提案

### 2. アイデアの構造化

```
💡 アイデア

タイトル: {アイデア概要}
解決する課題: {何が不便/不足か}
ざっくりイメージ: {どうなると嬉しいか}

PLAN.md に追記しますか？ (Y/n)
```

完璧な記述は求めない。思いついた時の鮮度を優先する。

### 3. PLAN.md に追記

PLAN.md を読み込み、`## アイデアバックログ` セクションを探す。

**セクションがある場合**: そのセクションの末尾に追記。

**セクションがない場合**: PLAN.md の末尾に以下を追加:

```markdown
## アイデアバックログ

開発中に思いついた機能アイデア。定期的に精査してロードマップに組み込む。
```

追記フォーマット:

```markdown
### {タイトル} ({今日の日付})

- **課題**: {解決する課題}
- **イメージ**: {ざっくりイメージ}
- **ステータス**: 未検討
```

### 4. 確認

```
💡 アイデア記録完了
   → PLAN.md / アイデアバックログに追記しました
   タイトル: {タイトル}
```

## 注意

- アイデア記録後に作業を中断しない。記録して即元の作業に戻る
- PLAN.md がない場合は「PLAN.md がありません。作成しますか？」と聞く
- 既に似たアイデアがある場合は重複を指摘し、既存エントリの更新を提案する
- アイデアのステータスは `/retro` や計画セッションで更新する想定
